          II. MÉTHODOLOGIE DE SCORING - GRILLE INTERACTIVE
================================================================================

CRITÈRES ET PONDÉRATIONS (SCORING PONDÉRÉ)
-------------------------------------------

1. IMPACT (30%)
   Valeur métier générée (couverture, décisions, visibilité)
   • Échelle : 1-5 (faible → élevé)
   • Questions : Combien d'utilisateurs impactés ? Quelle valeur métier créée ?
   • Exemples Impact 5/5 : Standardisation import, Scoring multi-critères

2. URGENCE (20%)
   Pression temporelle / dépendances bloquantes
   • Échelle : 1-5 (peut attendre → bloquant)
   • Questions : Y a-t-il des dépendances ? Des engagements contractuels ?
   • Exemples Urgence 4/5 : QA géo automatisée, Export analytique rapide

3. EFFORT (poids -20%, inversé)
   Complexité & charge estimée
   • Échelle : 1-5 (simple → très complexe)
   • Pondération négative : effort élevé réduit le score
   • Questions : Combien de jours/sprints ? Quelles compétences requises ?
   • Exemples Effort 2/5 : Lazy loading carte, Standardisation import

4. RISQUE (poids -10%, inversé)
   Incertitudes techniques / adoption
   • Échelle : 1-5 (maîtrisé → très incertain)
   • Pondération négative : risque élevé réduit le score
   • Questions : Technologie mature ? Dépendances externes ? Adoption garantie ?
   • Exemples Risque 4/5 : API publique (sécurité, quotas)

5. ALIGNEMENT (20%)
   Concordance avec vision & roadmap
   • Échelle : 1-5 (divergent → aligné totalement)
   • Questions : Contribution à la proposition de valeur ? Cohérence stratégique ?
   • Exemples Alignement 5/5 : Standardisation, Scoring, Scénarios réhabilitation

6. QUALITÉ DES DONNÉES (10%)
   Amélioration de qualité / standardisation
   • Échelle : 1-5 (sans impact données → amélioration majeure)
   • Questions : Complétude améliorée ? Conformité géostandard ?
   • Exemples Données 5/5 : Standardisation import, QA géo, Dashboard qualité

FORMULE DE CALCUL DU SCORE
---------------------------
Score total = Σ (poids * (valeur / 5))

Exemple : Standardisation import
• Impact 5 × 0.30 = 0.30
• Urgence 4 × 0.20 = 0.16
• Effort 2 × (-0.20) = -0.08
• Risque 2 × (-0.10) = -0.04
• Alignement 5 × 0.20 = 0.20
• Données 5 × 0.10 = 0.10
→ Score total = 0.64 (64%)

QUADRANTS DE PRIORISATION
--------------------------
Déterminés par Score & Effort :

🟢 QUICK WIN (Score ≥55% + Effort ≤2.5)
   → Livrer tôt pour accélérer adoption & crédibilité
   → ROI immédiat, complexité faible
   → Exemples : Standardisation import, Lazy loading carte

🟦 LEVERAGE (Score ≥50% + Effort ≤3.5)
   → Fort levier sur valeur, planification rapprochée
   → Impact élevé, effort modéré
   → Exemples : QA géo automatisée, Dashboard qualité, Export analytique

🔵 STRATEGIC BET (Score ≥45% + Effort >3)
   → Nécessite validation, jalons & pilote
   → Impact stratégique majeur, investissement lourd
   → Exemples : Scoring multi-critères, Migration PostGIS, Scénarios réhabilitation

⚫ MONITOR (Score <45% ou Effort >4 sans valeur correspondante)
   → Surveiller, requalifier plus tard
   → ROI incertain ou effort disproportionné
   → À reconsidérer selon évolution contexte

   • Grille Interactive : Effort 5/5, risque 3/5

   • Impact : Perte confiance utilisateurs, utilité plateforme réduite

     - Dashboard qualité visible (transparence, incitation amélioration)
     - Référents territoriaux formés (validation rigoureuse)

   • Impact : Automatisation bloquée, enrichissement impossible
