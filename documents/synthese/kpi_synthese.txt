================================================================================
                        I. LES 5 KPI ESSENTIELS
================================================================================

KPI 1 - QUALITÉ DONNÉES (Complétude & Géolocalisation)
-------------------------------------------------------
Mesure : % de friches avec données complètes (>80% champs critiques renseignés)
         ET coordonnées géographiques valides

Formule : (Friches complètes ET géolocalisées / Total friches) × 100
Baseline : 50%  |  Cible 6 mois : 80%  |  Cible 12 mois : 90%
Fréquence : Mensuel

Champs critiques (12) : nom, commune, département, adresse, latitude, longitude,
type_friche, surface, statut, pollution_sol, pollution_batiments, date_maj

Actions prioritaires :
✓ Standardisation import (gabarit CSV + validation automatique)
✓ QA géo automatisée (détection aberrations, enrichissement BAN)
✓ Croisement bases externes (BASIAS, BASOL, SIRENE)
✓ Workflow contribution collaborative (décentralisation saisie)


KPI 2 - ADOPTION UTILISATEURS (Usage actif plateforme)
-------------------------------------------------------
Mesure : Taux d'utilisateurs actifs mensuels (sessions carte + filtres + exports)

Formule : Utilisateurs actifs mensuels / Utilisateurs inscrits totaux
Baseline : 35%  |  Cible 6 mois : 60%  |  Cible 12 mois : 75%
Fréquence : Hebdomadaire

Métriques secondaires :
• Sessions carte/semaine : 40 → 120
• Durée session moyenne : >8 min
• Taux rebond : <40%

Actions prioritaires :
✓ UX optimisée (onboarding, lazy loading, synchronisation tableau↔carte)
✓ Fonctionnalités valeur ajoutée (analytics, exports multiformats)
✓ Communication régulière (newsletters, webinaires, ambassadeurs)


KPI 3 - EFFICACITÉ PIPELINE (Temps intégration & MAJ)
------------------------------------------------------
Mesure : Délai moyen entre découverte d'une friche et disponibilité dans plateforme

Formule : Temps moyen identification → intégration (heures ou mois selon phase)
Baseline : 16h import + 12 mois MAJ  |  Cible Phase 1 : 6h + 6 mois  |  Phase 2 : 2h + 3 mois
Fréquence : Mensuel

Actions prioritaires :
✓ Pipeline ETL optimisé (mapping automatique, traitement batch asynchrone)
✓ Connecteurs automatiques (Sit@del détection projets temps réel)
✓ Workflow validation rapide (validation automatique + référents territoriaux)


KPI 4 - AIDE DÉCISION (Friches priorisées avec scoring)
--------------------------------------------------------
Mesure : % de friches avec score de priorisation calculé et utilisé pour décisions

Formule : (Friches avec score calculé / Total friches) × 100
Baseline : 0%  |  Cible Phase 2 : 40% (pilote)  |  Phase 3 : 70% (national)
Fréquence : Mensuel

Critères scoring (6-8) : Surface, localisation, pollution, statut foncier,
                         desserte transports, tension foncière locale, coût estimé

Actions prioritaires :
✓ Module scoring multi-critères (conception + atelier pondérations Phase 2)
✓ Interface simplifiée (sliders, visualisation scores, comparateur)
✓ Pilote 3-5 territoires (validation approche, ajustements itératifs)


KPI 5 - IMPACT ZAN (Reconversions suivies)
-------------------------------------------
Mesure : % de friches ayant évolué positivement (en projet, requalifiée) sur 12 mois

Formule : (Friches statut évolué / Total friches) × 100 sur période glissante 12 mois
Baseline : Non mesuré  |  Cible Phase 3 : 10%  |  Phase 4 : 15%
Fréquence : Trimestriel

Métriques complémentaires :
• Surface artificialisée évitée : 500 ha/an
• Logements créés : suivi post-projet
• Emplois créés/préservés : suivi post-projet

Actions prioritaires :
✓ Historisation données (tracking évolution statuts automatique)
✓ Module impact ZAN (calcul surface évitée, contribution objectifs territoriaux)
✓ Fiches bilan projets (avant/après, documentation REX)
