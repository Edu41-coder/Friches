MVP – Application Friches

Définition solution minimale & évolutions • Version:

1. Vision

Offrir une base unifiée, fiable et exploitable des friches industrielles pour accélérer la planification territoriale, améliorer la priorisation des réhabilitations et accroître la transparence des données environnementales et foncières.

Centralisation unique
Exploration rapide (table + carte)
Qualité observable
Décision priorisée

2. Périmètre MVP (Essentiel)

  • Authentification (admin / user) basique sécurisée (sessions, bcrypt)
  • Tableau interactif: pagination serveur, tri colonnes, filtres texte/sélection
  • Sélection colonnes + mémorisation préférences
  • Carte Leaflet avec markers + clustering + popup info clé
  • Import standardisé (CSV gabarit) manuel (script / interface simple)
  • Qualité géolocalisation: validation lat/long + taux de complétude visible
  • Statistiques globales de base (compte friches, surfaces agrégées)
  • Audit modifications (création / mise à jour / suppression)
  • Export CSV filtré depuis tableau
  • Sécurité : PDO préparé, protections CSRF basiques
Objectif: Publication interne utilisable par urbanisme & analyste dans un délai court sans dette structurelle majeure.

3. Hors Scope Initial (Exclusions MVP)

  • Scoring multi-critères complet (phase post-MVP)
  • API publique externe
  • Analyse avancée pollution (croisement sources spécialisés)
  • Simulation scénarios de réhabilitation
  • Interface d'import multi-formats (Excel, GeoJSON) automatique
  • Gestion fine des rôles multiples / permissions granulaires
  • Vector tiles / rendu GL haute performance

4. Fonctionnalités Futures (Phases)

Phase 2

  • QA géo automatisée (bbox FR, duplication, anomalies)
  • Dashboard qualité (complétude, fraîcheur)
  • Exports analytiques enrichis
  • Lazy loading carte par bounding box

Phase 3

  • Scoring multi-critères (surface, statut, risque)
  • Analytique avancée (distribution surfaces, pollution)
  • Migration PostGIS (requêtes spatiales)
  • Notifications anomalies data

Phase 4

  • API publique lecture sécurisée
  • Scénarios & simulation de réhabilitation
  • Intégration données propriétaires / cadastre avancé
  • Exports géospatiaux (GeoJSON, shapefile)

Phase 5

  • Modèle prédictif (priorisation probabiliste)
  • Tableau de bord impact (suivi réhabilitations)
  • Rendu vector tiles / performance ++
  • Rôles personnalisés & SSO

5. Stack Technique Minimale

Frontend

  • HTML5 / CSS3 (Bootstrap styles de base + custom)
  • JavaScript vanilla (modules utilitaires AJAX)
  • Leaflet + MarkerCluster
  • Chart.js (stats de base)

Backend

  • PHP 8 MVC léger
  • MariaDB (tables friches, users, audit)
  • PDO + requêtes préparées
  • Sessions + bcrypt + CSRF token simple

Outils Data

  • Scripts Python (nettoyage, import CSV)
  • Gabarit CSV défini + dictionnaire
  • Validation coordonnées & colonnes

Observabilité

  • Logs import (durée, erreurs)
  • Audit CRUD friches
  • Compte qualité géoloc / complétude
