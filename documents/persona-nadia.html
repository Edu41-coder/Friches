Persona – Nadia

Analyste territoriale / Data insight • Version:
N
Profil
Âge: 29 Contexte: Produit des analyses quantitatives pour soutenir les arbitrages stratégiques. Motivation principale: Générer des insights solides et comparables pour prioriser les investissements.
« Les tendances visuelles m'aident à raconter une histoire convaincante. »

Objectifs

  • Produire des rapports visuels rapides
  • Comparer répartition par type / statut / commune
  • Détecter clusters géographiques à fort potentiel
  • Identifier corrélations pollution / surface / statut
  • Alimenter les comités de pilotage avec des KPIs

Tâches clés

  • Consulter dashboard analytique
  • Exporter graphiques (captures ou PDF print)
  • Segmenter jeux de données (filtres combinés)
  • Préparer slides synthèse
  • Proposer axes prioritaires aux décideurs

Douleurs / Frictions

  • Manque de granularité sur temporalité
  • Nettoyage manuel avant usage externe
  • Doute sur qualité pollution déclarée
  • Absence d'histogrammes multi-échelles avancés
  • Besoins croisés avec autres datasets (emploi, transport)

Besoins / Attentes

  • API ou export structuré (JSON/CSV)
  • Graphiques interactifs et filtrables
  • Indicateurs agrégés (top 10, moyennes, surfaces)
  • Possibilité mode log pour distribution surfaces
  • Stabilité des colonnes & définitions

Indicateurs (KPIs)

  • Délai génération rapport
  • Nb d'analyses mensuelles
  • Taux réutilisation des graphiques
  • Demandes décideurs satisfaites
  • Qualité perçue (feedback interne)

Outils utilisés

  • Application Friches (analytics + carte)
  • Tableur / BI léger
  • Outils de présentation (slides)
  • Scripts ad hoc (échantillonnage)
  • Référentiel codes INSEE

Segments critiques

  • Type / statut friche
  • Surface (normal + log)
  • Commune + regroupements géo
  • Pollution sol vs bâti
  • Activité passée / propriétaire type

Citation

  • « Un top 10 clair des communes les plus touchées fait gagner du temps à tout le monde. »

Risques si non servi

  • Analyses tardives ou incomplètes
  • Orientation des investissements sous-optimale
  • Perte de crédibilité analytique
  • Difficulté à convaincre les financeurs

Initiatives futures

  • Module séries temporelles
  • Export dataset filtré direct
  • Scores de potentiel automatique
  • Comparaison inter-régions dynamique
