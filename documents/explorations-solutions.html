Explorations de pistes de solutions

Hypothèses, expériences, critères de décision • Version:

1. Axes problème

Qualité & Standardisation

  • Hétérogénéité formats (CSV, Excel)
  • Colonnes critiques manquantes
  • Géolocalisations erronées

Exploration & Décision

  • Filtres combinés multi-critères
  • Vision géographique claire
  • Arbitrage priorisation

Performance & Échelle

  • Carte avec milliers de points
  • Chargement par zone
  • Cache & coûts requêtes

2. Pistes de solutions

2.1 Import standardisé + Dictionnaire

Valeur Gabarits CSV + mapping colonnes pour ingestion fiable.

Impact Élevé • Effort Faible/Moyen

Expériences: prototyper gabarit, importer 2 lots réels

2.2 QA géo automatisée

Valeur Détection coordonnées hors France, doublons, inversions lat/lon.

Impact Élevé • Effort Moyen

Expériences: script Python + seuils d'alerte

2.3 Dashboard qualité

Valeur Visibilité complétude, fraîcheur, erreurs import.

Impact Élevé • Effort Moyen

Expériences: page Chart.js avec 3 métriques

2.4 Lazy loading carte

Valeur Performance sur gros volumes via requêtes par bbox.

Impact Élevé • Effort Moyen

Expériences: endpoint bounds + test 100k points synthétiques

2.5 Scoring multi-critères

Valeur Aide à l'arbitrage (surface, statut, risques, proximité).

Impact Élevé • Effort Élevé

Expériences: atelier pondérations + pilote sur 1 territoire

2.6 Migration PostGIS (étude)

Valeur Requêtes spatiales avancées (intersections, buffers).

Impact Moyen/Élevé • Effort Élevé

Expériences: POC petite table + comparaison perfs

4. Expériences proposées

XP-01 Import gabarit

  • Livrable: gabarit CSV + script validation
  • Succès: import 2 jeux réels sans correction manuelle
  • Durée: 3 jours

XP-02 QA géo

  • Livrable: script détection anomalies
  • Succès: >90% anomalies identifiées automatiquement
  • Durée: 4 jours

XP-03 Dashboard qualité

  • Livrable: page 3 métriques clés
  • Succès: taux complétude affiché par champ
  • Durée: 4 jours

XP-04 Lazy loading

  • Livrable: endpoint bbox + front
  • Succès: temps affichage < 1.5s à 50k pts
  • Durée: 5 jours

5. Critères de décision

  • Impact mesurable sur KPIs (qualité/usage/efficacité)
  • Effort < 1 sprint pour Go direct, sinon pilote
  • Risque maîtrisable (technique, données, adoption)
  • Alignement MVP et roadmap

6. Recommandations

  • Lancer Import standardisé + QA géo + Dashboard qualité en priorité
  • Préparer lazy loading carte avant montée en charge
  • Conduire pilote scoring multi-critères sur périmètre restreint
  • Étudier migration PostGIS après consolidation qualité
